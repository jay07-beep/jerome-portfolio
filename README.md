# Jérôme Desale — Portfolio

Personal engineering portfolio focused on e-Healthcare, Data Science, AI,
biomechanics and sports analytics.

## Local preview

Requirements: Node.js 22 or newer.

```powershell
npm.cmd install
npm.cmd run dev
```

Then open `http://localhost:3000/jerome-portfolio/`.

## Production build

```powershell
npm.cmd run build
```

The static website is exported to `out/`.

## GitHub Pages

The repository contains a GitHub Actions workflow that publishes every push to
the `main` branch. See [GITHUB_PAGES_GUIDE.md](GITHUB_PAGES_GUIDE.md) for the
first-publication steps.

Public address after deployment:

`https://jay07-beep.github.io/jerome-portfolio/`
